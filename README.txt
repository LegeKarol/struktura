STRUKTURA – planer dnia (aplikacja PWA)

Instalacja na telefonie:
1. Wgraj CAŁY folder na hosting z HTTPS, np.:
   - Netlify Drop: wejdź na app.netlify.com/drop i przeciągnij folder,
   - GitHub Pages: wrzuć pliki do repozytorium i włącz Pages.
2. Otwórz adres w Chrome na Androidzie -> menu (⋮) -> "Zainstaluj aplikację".
   (iPhone: Safari -> Udostępnij -> "Do ekranu początkowego").
3. Aplikacja ma własną ikonę, działa na pełnym ekranie i offline.

Plik APK (opcjonalnie): wpisz adres hostingu na pwabuilder.com i wybierz "Android".

Uwaga: dane zapisują się lokalnie na urządzeniu (localStorage).
